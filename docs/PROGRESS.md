# Progress

Generated by `tools/progress.py` (`make progress`).

* **C functions (verified)**: compiled with IDO (7.1, or 5.3 for part of libultra) to bytes identical to the ROM.
* **Drafts to clean up**: verified, but still written with raw field offsets (`M2C_FIELD`) from the automatic draft; they become real struct accesses once the types are known.
* **Typed signatures**: verified functions that use the shared headers of `include/` (real types and parameter names, one prototype) instead of local placeholder types; see the rule in [CONTRIBUTING.md](CONTRIBUTING.md#code-style).
* **C bytes**: share of the segment's code bytes covered by verified C.
* **Original assembly**: hand-written in the original game or impossible in C; not counted in the denominator.
* **Attempts (wip)**: unfinished drafts in `src/<segment>/wip/`.
